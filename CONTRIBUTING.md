# Contributing

## Scope

Contributions should improve the accuracy, safety, reproducibility, or clarity of the portfolio.

## Required Changes

Before submitting a substantive finding, include:

- Exact model and version
- Deployment date and configuration
- Prompt and response evidence
- Rubric and intended outcome
- Trial count and exclusion rules
- Limitations
- Any sources used to adjudicate factual claims

## Submission Checklist

- [ ] No secrets or personal data
- [ ] No unsupported quantitative claims
- [ ] No simulated transcript presented as real output
- [ ] Health claims include appropriate caveats and reliable sources
- [ ] Prompt and response are reproducible or clearly marked as illustrative
- [ ] Markdown links and relative paths are valid
- [ ] Files are human-readable and concise

## Pull Requests

Keep changes focused and explain why an alteration improves evidence quality or repository usability.
